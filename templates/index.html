How Our Model Works

Advanced machine learning trained on thousands of games

📊

1. Data Collection

We analyze 2,000+ games worth of comprehensive statistics and game outcomes. We include offensive efficiency, defensive ratings, turnover ratios, and advanced metrics for every FBS or D1 team.

🧠

2. Machine Learning

Our regression model weighs dozens of factors to calculate team strength ratings. The algorithm learns optimal weights from historical performance to maximize prediction accuracy. These weights learn from every game that is played.

⚡

3. Prediction Generation

For each matchup, the model considers team ratings, statistical differentials, home court advantage, and neutral site factors to predict the margin and win probability. The model outputs the predicted winner, point margin along with the edge versus the vegas line
